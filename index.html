FORMULA INTI • FILTER + IF

IF memilih jalur filter; FILTER mengambil baris yang memenuhi kriteria.

=IF($A$7="Semua";
 FILTER('01_RAW_BQ'!$A$7:$H$23;
 ('01_RAW_BQ'!$H$7:$H$23>=$B$7)*('01_RAW_BQ'!$H$7:$H$23<=$C$7);
 "Tidak ada data");
 FILTER('01_RAW_BQ'!$A$7:$H$23;
 ('01_RAW_BQ'!$G$7:$G$23=$A$7)*('01_RAW_BQ'!$H$7:$H$23>=$B$7)*('01_RAW_BQ'!$H$7:$H$23<=$C$7);
 "Tidak ada data"))
  • A7 = status dropdown
  • B7 = tanggal mulai • C7 = tanggal akhir
  • G = Status Proses • H = Tanggal Permintaan
  • Tanda * berarti semua kondisi harus terpenuhi (AND).
POST MANAGEMENT DATASESI 6 • 07
Formula dimasukkan satu kali di A10. Pastikan area A10:H26 kosong. Formula memakai pemisah titik koma sesuai pengaturan Excel pada workbook peserta. Jika pilihan Semua, IF mengarahkan ke FILTER yang hanya menggunakan tanggal. Jika Include atau Review, FILTER memakai status dan tanggal.

TAHAP 2 • MASTER DATA LOOKUP

Lookup mengurangi input manual dan menjaga konsistensi data.

Kategori → kolom CHarga Satuan → kolom ESatu formula → dua kolom
=IF($A7="";"";XLOOKUP($B7;'02_MASTER_ITEM'!$B$5:$B$20;HSTACK('02_MASTER_ITEM'!$C$5:$C$20;'02_MASTER_ITEM'!$E$5:$E$20);"Tidak ditemukan"))
POST MANAGEMENT DATASESI 6 • 09
Letakkan formula di E7 saja. HSTACK menggabungkan kolom Kategori (C) dan Harga Satuan (E) dari Master Item, lalu XLOOKUP mengembalikan keduanya sekaligus ke E:F. Pastikan F7:F23 kosong agar spill tidak terhalang. HSTACK tersedia pada Excel Microsoft 365 versi baru. Jika Excel menampilkan #NAME? atau HSTACK tidak dikenal, gunakan dua XLOOKUP terpisah: satu untuk kategori di E7 (return C), satu untuk harga di F7 (return E).
TAHAP 3 • HITUNG BQ

Investasi awal dan alokasi bulanan menjawab dua pertanyaan berbeda.

BarangMop Set Biru
Quantity (C7)2 Pcs
Harga satuan (F7)Rp95.000
Siklus (D7)6 bulan
Investasi awal (G7)Rp190.0002 × Rp95.000

G7 — Investasi Awal=IF(OR(A7="";C7="";F7="");"";C7*F7)

POST MANAGEMENT DATASESI 6 • 10
Di layout BQ saat ini: C = Qty, D = Siklus (bulan), F = Harga Satuan, G = Investasi Awal, H = Estimasi Beban Bulanan (Alokasi). Masukkan rumus G7 dan H7, lalu copy down. IF di depan menjaga baris kosong tetap kosong; D7=0 mencegah #DIV/0!. Angka bulanan adalah alokasi simulasi investasi berdasarkan siklus, bukan recurring cost aktual untuk semua jenis barang.
TAHAP 4 • STATUS OTOMATIS

IF membantu menandai baris yang masih perlu diperiksa.

OK

Kategori, harga, investasi, dan alokasi terisi

PERIKSA

Lookup gagal atau ada kolom wajib kosong

Kosong

Belum ada Request ID

=IF($A7="";"";IF(OR($E7="Tidak ditemukan";$F7="";$G7="";$H7="");"PERIKSA";"OK"))
POST MANAGEMENT DATASESI 6 • 11
Masukkan formula di I7 lalu copy down. A = Request ID, E = Kategori, F = Harga, G = Investasi Awal, H = Estimasi Beban Bulanan. Jika baris kosong, status kosong. Jika lookup tidak ditemukan atau kolom wajib kosong, PERIKSA. Jika seluruh input terisi, OK. Status OK hanya pemeriksaan kelengkapan dasar, bukan audit kewajaran harga atau qty.
